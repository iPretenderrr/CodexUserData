# CodexUserData 1.8.3 · 使用说明

完整解压后双击 `CodexUserData.exe`。支持 Windows 10 / 11 x64，需要 .NET Framework 4.8。自定义 HTML 形态还需要 Microsoft Edge WebView2 Runtime。本程序为未签名便携版。

## 本版更新

- 新增额度历史曲线，只显示 5 小时和 7 天额度，未提供的周期不显示；两条曲线使用不同颜色。
- 支持 1h、3h、6h、12h、1d、7d、14d、30d、60d、90d、180d；清除选择按钮位于右侧。
- 曲线平滑显示，额度重置保留跳变，查询缺失时段断开；点击查看明细，点击图例显隐对应曲线。
- 沿用每分钟在线查询，成功后记录，历史保留 180 天；后台读写和绘图缓存减少交互开销。
- 在顶部图表按钮打开的窗口中切换到“额度”。首次使用此版本后开始积累记录，升级后继续保留。

## 1.8.2 更新

- 经典卡片精简为用量与额度，去除常驻操作说明和来源页脚，按周期数量收窄并降低展开高度。
- 玻璃小版采用单行 Tokens 与垂直居中的额度环；展开后再显示标签和任务数量。

## 1.8.1 更新

- 待机与运行采用统一高度，展开保持胶囊比例；只有一个额度周期时自动收窄。
- 单击即时展开，修复按压与拖动衔接；展开期间只动画绘制区域，减少原生窗口反复调整尺寸。
- 改善主窗口与悬浮窗的交叉过渡，修复反向切换重置透明度；自动伸缩不再触发配置写盘。

- 单击灵动岛可原位展开或收起额度明细，双击返回主界面；右键切换形态或锁定位置。
- 灵动岛沿用四边吸附、透明度、主题渐变与动画档位，完成提示保留到鼠标移入确认。

## 常用操作

- 主窗支持拖动、置顶和任意边框缩放；窗口较小时自动精简。顶部图表按钮可打开完整图表。
- 曲线点击后显示明细，清除选择可收起；悬停图例高亮对应模型。热度图的每日明细独立显示，随整页滚动。
- 圆环显示剩余额度，小胶囊显示今日 Tokens，大胶囊同时显示额度。右键可切换形态或返回主界面；圆环双击可返回。
- 拖到屏幕边缘并松开可收为细额度条，拖离可恢复。悬停额度条不会自动展开。开启位置锁定后需解锁才能拖动，仍可返回主界面。
- 运行时悬浮形态和托盘显示动效；明确完成后提示保留到鼠标移入确认。未确认时开始新任务会恢复运行效果。
- 默认最小化到任务栏，可在设置中改为托盘；双击托盘恢复窗口。退出按钮结束软件。

## 设置

设置分为外观与主题、悬浮球、数据显示、数据与额度、启动与行为、关于软件六类。

- 深色、浅色和自定义主题；自定义支持最多 5 色渐变。主窗和悬浮球透明度分别调整，圆环默认跟随主题。
- 动画档位为自动、完整、轻量、关闭。低性能设备可选轻量；关闭后保留静态状态提示。动画速率 0.5×–2× 控制界面切换快慢。
- 模型价格以编辑器标注的 USD / 百万 Tokens 为单位。先“应用到设置”，再“保存设置”，历史记录随新价格重新估算。
- 数据来源可选本地 Codex 日志或 CC Switch 数据库，两者独立统计、不相加。默认路径不存在时选择本机路径。
- 在线额度需要本机可用且已登录的 Codex CLI。可自动检测或手动选择 `codex.exe`；没有 CLI 不影响读取已有本地日志。
- 开机自启动与随 Codex 启动互斥，默认关闭。移动程序文件夹后启动一次软件，更新已启用的启动路径。
- HTML 形态通过 `shape.json` 导入，只使用可信形态。任意位置右键或 Esc 可返回主界面；Alt + 拖动可移动。加载失败可切回内置形态。示例见 `examples/aurora`。

Tokens 是输入（含缓存）加输出，推理已包含在输出中。API 等效价值是估算，不是实际账单；未设置的价格项按 0 估算，不代表免费。任务状态仍受日志写入延迟和记录完整性影响，未知不等于已完成。额度请同时查看来源及更新时间，过期后不推算余额。

## 更新与个人数据

在“设置 → 关于软件”主动检查更新并查看发布说明，不会自动下载或安装。退出旧版后完整解压新版并运行，覆盖原程序目录或换目录均可；不要同时运行新旧版本。

设置、价格、自定义形态、额度历史和缓存保存在当前 Windows 用户的 `%LOCALAPPDATA%\CodexUserData`，同一用户的新版继续读取此目录。备份时先退出软件，再私下复制该目录。换电脑或换 Windows 用户需另行迁移并重新选择本机路径。采用程序旁 `data` 文件夹的旧版用户，请先保留旧 data，并在原目录启动新版完成迁移。

反馈问题时可在关于软件中预览脱敏诊断，再选择保存完整预览文本到本机；软件不会自动上传。不要分享原始日志、数据库、账号凭据、用户数据目录或真实隐私截图。给别人发软件只发送发布 ZIP。
