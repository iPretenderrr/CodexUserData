# CodexUserData · 仅程序版

解压后双击 `CodexUserData.exe`，无需安装开发工具。支持 Windows 10 / 11 x64，需要 .NET Framework 4.8。本便携版未进行代码签名。

程序读取使用者自己的本地 Codex 日志或 CC Switch 数据库。默认位置不存在时，请在设置中选择自己的路径。在线额度需要使用者本机已安装并登录的 Codex CLI；找不到时可以手动选择 `codex.exe`，本地用量统计仍可使用。

## 操作

- 主窗支持拖动、置顶、缩放及自动精简；设置按外观、悬浮球、数据显示、数据与额度、启动与行为、关于软件分为六类，可查看版本和数据位置，并调整透明度、刷新时间、显示指标和模型价格。
- 设置 → 外观主题：选择深色、浅色或自定义。自定义支持 1–5 个颜色、色点位置、线性／径向渐变、角度与范围、镜像／重复，以及卡片透明度；实时预览，点击保存后保留。
- 热度图支持悬停和点击查看；曲线点击后显示明细，图例悬停高亮。明细统一随整页滚动。
- 默认悬浮球使用渐变圆环：只有一个有效周期时，显示单环和居中的大号百分比；两个周期时，外圈为短周期、内圈为长周期。彩色长度和百分比都表示剩余额度，均不可用时显示待更新。
- 任务活动或鼠标悬停时，彩色环产生弹性波浪和扭动；按下收缩，单击回弹并泛起光波，中心数字保持稳定。双击返回主窗，按住拖动，右键可切换大小胶囊。
- 设置中可选圆球尺寸、贴边额度条的周期，以及自动、流畅、节能、关闭动画四个档位。空闲且交互结束后停止绘制动画，隐藏时停止动画和界面计时。
- 大小胶囊检测到任务运行时，整个窗口背景会呼吸并有主题渐变光扫过，最外侧圆角边框同步显示带渐隐拖尾的连续环绕流光；任务结束、隐藏窗口或关闭动画后立即停止。流畅档使用 60 FPS，节能、低端渲染或电池供电时自动降为 30 FPS。
- 设置 → 圆环配色：默认跟随整体主题渐变。关闭跟随后，短周期和长周期可分别选择 1–5 种颜色及渐变角度，支持选色器、颜色代码、演示预览和恢复默认。保存配色后，还需保存设置。
- 粒子、流光与圆环配色一致，底盘随圆环轻微起伏。中心上方的小亮点表示检测到任务活动；悬停只触发动效，不会点亮该标记，也不会弹出提示文字或明细。
- 主窗口、圆球和托盘均按独立的每秒检测更新任务状态，不受用量刷新间隔影响。优先使用任务开始、完成与中断事件；后台审查、旧日志和额度快照不会作为用户任务。较长时间无新事件时显示待确认，不把超时当作完成。状态仍受日志写入延迟影响。软件在任务中途启动、日志损坏、缺少生命周期事件或积压大量新增内容时，可能延迟或只能待确认；不能保证任意时刻零延迟。
- 设置中可关闭“任务完成后闪烁提示”：在明确完成后让可见窗口持续柔和闪烁，托盘交替显示完成标记与额度环。鼠标移入悬浮窗或托盘即确认并停止；未确认时开始新任务，会取消完成提示并恢复运行效果。不会抢占焦点或打开窗口；系统关闭动画时托盘保持静态完成标记直到确认。启动时的历史完成记录不触发。
- 托盘使用接近满画布的粗线渐变额度环，缩小到 Windows 托盘尺寸后仍更容易辨认；颜色跟随深色、浅色或自定义主题。环长表示长周期余额（没有长周期时使用短周期），运行任务时以缓存帧柔和呼吸。准确百分比在展开卡片中显示；悬停或单击可查看独立额度卡、重置时间、任务状态与今日用量；较旧或已过重置时间的额度显示待更新。
- 主窗口、设置、模型价格、圆环配色、图表、悬浮形态和托盘速览使用统一的淡入、轻微缩放与位移动效，设置分类和右键菜单也使用短过渡。首次显示会先完成布局与定位再进入动画，避免闪动或从错误位置跳入。Windows 关闭界面动画、高对比度或低端渲染模式下会自动简化。
- 贴边后显示细额度条。检测到任务运行时，额度条轻微呼吸并有光带流过；任务停止或状态待确认时恢复静态。完成提示仍按原设置持续到鼠标确认。脉冲跟随主题渐变，不改变额度比例；隐藏或拖离边缘时停止，动画关闭选项同样生效。拖离恢复圆球或小胶囊，悬停额度条不会展开。
- 默认最小化到任务栏，设置中可改为托盘。双击托盘图标恢复窗口；主窗退出按钮退出软件。

## 个人数据

设置、自定义价格、用量索引缓存、自定义形态与 HTML 浏览器缓存统一存放在 `%LOCALAPPDATA%\CodexUserData`，与程序解压位置、版本号无关。同一 Windows 用户共享这一目录。1.4 用户请先在原程序目录启动新版，迁入旧 data 中较新的设置、缓存与形态；替换的内容保存在 migration-backups，旧 data 原件保留。HTML 浏览器缓存重新生成。该目录不属于分享包，请勿转发。程序只读访问原始日志和数据库，在线额度由用户自己的 CLI 查询。

本压缩包不含程序源码、构建脚本、混淆映射、调试符号、作者的设置、日志、缓存或账号凭据。

Tokens 为输入（含缓存）加输出，推理已含在输出中。两个来源独立统计，不相加。API 等效价值是参考估算，不是订阅账单；可在设置中更新价格。没有价格或留空的项目按 0 估算，不代表免费。缺少原会话、无法排除重复历史的记录暂不计入，额度过期不推算余额。

本程序经过名称混淆和字符串隐藏；这些措施增加逆向阅读难度，无法保证阻止反编译。

## 更新与数据保存

- 设置中的“悬浮球整体不透明度”作用于圆环、大小胶囊、贴边条和 HTML 形态，范围 20%–100%，与主窗口独立。
- 设置中可开启“随 Codex 启动”：登录 Windows 后保留轻量后台检测器，约每两秒检查本机 Codex 桌面端或 CLI 是否出现，再启动悬浮窗。手动退出后，在当前 Codex 进程持续运行期间不再拉起。关闭此选项并保存可停止检测器。此功能与直接开机打开主窗口互斥，默认关闭；不会修改 Codex 的启动文件或登录信息。
- 设置中可开启“开机自启动”，默认关闭。移动程序文件夹后重新启动软件，以更新自启动路径。
- CLI 路径不存在时自动检测本机安装位置；设置中还有“自动检测”和“手动选择”。依次查找 PATH 中的可执行文件/包、用户 npm 与配置的全局目录、编辑器扩展、桌面应用路径。全部失败会提示，不影响读取本地用量日志。
- 设置中导入 HTML 形态的 `shape.json`，保存后使用悬浮球按钮进入。右键菜单始终由程序提供，可返回主界面。Alt + 左键拖动可移动；Esc 返回主界面。示例位于 `examples/aurora`，开发接口见 `docs/HTML形态接口.md`。
- HTML 形态需要 Microsoft Edge WebView2 Runtime：[微软官方下载](https://developer.microsoft.com/microsoft-edge/webview2/)。依赖缺失或形态加载失败时可右键切回内置形态。
- 操作说明书见 `docs/CodexUserData-使用说明书.html` 或 PDF，截图全部使用演示数据。

后续更新时：退出旧程序，解压新版后运行 CodexUserData.exe；覆盖原程序目录或换一个目录均可，同一 Windows 用户会读取相同的数据。不需要随程序复制个人数据。设置中点击“打开用户数据目录”可进行备份。1.4 首次迁移前请保留旧 data，并先在旧程序目录运行新版；不要同时运行新旧版本。

换目录使用：复制程序文件即可，无需迁移用户数据目录。换 Windows 用户或换电脑不会自动共享数据；如需迁移，退出软件后自行备份并复制用户数据目录，并重新选择新电脑的 Codex 数据目录与 CLI。1.4 仍采用旧的便携路径，无法自动改成新的存储行为。

给别人发送时只发送发布 ZIP，不要附上用户数据目录或旧版 data；其中包含个人设置和用量信息。卸载前若开启过开机自启动或随 Codex 启动，先在设置关闭，再退出删除程序目录。
